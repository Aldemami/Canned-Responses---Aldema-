# Canned Reply Assistant

Competition-ready Big Brain Studio app for monday.com's Business Support team.

The app code lives in [`canned-reply-assistant/`](./canned-reply-assistant), which is structured as a standalone React + TypeScript app folder so it can be dropped into a Big Brain Studio workspace as the slug folder `canned-reply-assistant`.

## What it includes
- Explainable top-3 canned reply suggestions for Business Lounge tickets
- Searchable canned-library browser with group counts
- “Add a great answer” workflow with duplicate detection and write gating
- Demo mode using the bundled canned-library snapshot plus anonymized sample tickets
- Gap finder that clusters under-covered topics and drafts new canned replies
- Dashboard with volume, coverage, impact estimates, and local event-model design
